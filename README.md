# Data Cleansing Pemain Sepak Bola

## Deskripsi
Project ini merupakan penerapan data cleansing pada dataset pemain sepak bola menggunakan Python dan Pandas.

## Dataset
Dataset yang digunakan adalah data mentah pemain sepak bola yang terdiri dari 30 data pemain.

## Proses Data Cleansing
1. Standarisasi ID Pemain
2. Standarisasi Nama Pemain
3. Standarisasi Usia
4. Standarisasi Jenis Kelamin
5. Standarisasi Posisi
6. Standarisasi Kaki Dominan
7. Standarisasi Penampilan
8. Cleansing Gol
9. Cleansing Assist
10. Standarisasi Menit Bermain
11. Standarisasi Status
12. Pemeriksaan Data Duplikat
13. Pemeriksaan Missing Value
